GitLab is not supported by this version yet; the agents would be told GitHub commands. Use a version that supports it, or remove the key.

This profile says `"forge": "gitlab"`. Nothing is wrong with the project: this version of the
plugin only knows how to work with GitHub, and a brief printed for a GitLab project would
dictate `gh` commands and promise refusals that GitLab does not give. Tell the human this,
and stop: do not run the workflow with the commands of another forge.
